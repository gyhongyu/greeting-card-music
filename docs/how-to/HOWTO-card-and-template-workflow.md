# HOWTO: 卡片與模板分工操作指南 (Workflow Guide)

## 📌 概念區隔 (Core Separation)

| 維度 | 模板 (Template) | 卡片 (Card) |
|------|----------------|------------|
| **檔案定義** | `data/templates.json` | `data/cards.json` |
| **本質** | 視覺與排版規範（藍圖 Blueprint） | 具體祝賀內容（實例 Instance） |
| **內含屬性** | WebGL 背景 Shader、3D 粒子特效、字體、主色調、星戰速度 | 卡片名稱、主標題、受眾稱謂、祝詞正文、照片、署名、templateId |
| **受眾視角** | 僅含佔位示範文案（`TEMPLATE_DUMMY_CARD`），**禁止轉發** | 正式生成分享連結（`?card=xxx`），**專為受眾呈現** |

---

## 🚀 典型工作流程

### 1. 建立或微調視覺風格 (Template Studio)
1. 進入首頁，切換至 `【🛠️ 模板管理】` 頁籤。
2. 點擊每張模板下方的 `[✏️]` 圖示，彈出「自訂設計模板與 3D 特效微調」視窗。
3. 調整 Shader（如絲綢金煙、軌道行星）、粒子（如神聖星塵、流星雨、落櫻）與滾動速度。
4. 點擊 `[👁️]` 試看佔位文案的排版質感。
5. 點擊「保存模板規格」即可。

### 2. 製作並分發專屬賀卡 (Card Creator)
1. 進入首頁 `【🗂️ 卡片管理】` 頁籤。
2. 點擊 `[＋ 新增卡片]`，系統自動切換至編輯器，並套用預設模板。
3. 在左側選擇想要套用的外觀模板（點擊即時更換整體光影）。
4. 在右側輸入主標題、受眾稱謂、祝詞與照片清單。
5. 中間即時目測手機 (9:16) 或寬屏 (16:9) 效果。
6. 點擊頂部 `[← 返回卡片庫]` 保存並退出。
7. 在首頁卡片上點擊 `[分享]`，複製專屬連結發送給家人、朋友或商務夥伴。

### 3. 資料備份與發布
- 點擊頂部導覽列 `[備份導出]`，可將當前的所有卡片與模板打包下載為 JSON 檔案。
